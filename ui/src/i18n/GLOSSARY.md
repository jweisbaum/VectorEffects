# Translation glossary

The terms the interface and the help reference use for the application's own
concepts, fixed so every area — and every later feature — says the same thing.
The audience is sailors and forecasters: prefer the nautical and
meteorological word a chart or a forecast in that language would use.

Register: Spanish and German address the reader formally (usted, Sie) in
sentences; French uses vous. Button and menu labels are infinitives in French
and Spanish ("Enregistrer", "Guardar") and infinitives or nouns in German
("Speichern").

Punctuation: French puts a narrow space before `: ; ? !` and uses « »; German
uses „ “; Spanish uses « ». Keep `…` where the English has it (it means "opens
a dialog"). Keep every `{placeholder}` exactly as written.

Never translated: VectorEffects, GRIB, GRIB2, Zarr, UTC, EPSG, PROJ, WKT, MCP,
ERA5, GlobCurrent, OpenStreetMap, S-57, GIS, KML, GPX, GeoJSON, Claude Code,
Codex, Claude Desktop, file extensions, unit symbols (kt, km, nm, mph, km/h,
m/s, px, °, h).

Italian, Dutch, Japanese, Simplified Chinese and Arabic keep their terms in
`GLOSSARY.<lang>.md` beside this file, in the same order as the table below.
Japanese uses the polite form (です/ます) in sentences and plain nouns or
verb stems on buttons; Chinese is Simplified, with full-width punctuation in
sentences; Arabic is Modern Standard Arabic with Western digits, and is shown
right to left (spec §5.7); Italian uses the impersonal and infinitive forms usual in
software ("Fare clic per…", "Salva"); Dutch addresses the reader as u.
