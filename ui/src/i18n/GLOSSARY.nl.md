# Woordenlijst Nederlands

The Dutch terms for the application's own concepts, in the same order as the
table in `GLOSSARY.md`. Chosen as a Dutch nautical chart, a KNMI forecast or
Dutch software would say them.

Register: sentences address the reader as u ("Open een project", "U kunt…").
Buttons and menu items are infinitives ("Opslaan", "Laag toevoegen").
Quotation marks are „ ” or ‘ ’; keep `…` where the English has it and every
`{placeholder}` exactly as written. The never-translated list of
`GLOSSARY.md` applies unchanged.

Keys: Dutch macOS writes Command, Option, Control, Shift, Return, Tab, Delete
and spatiebalk; arrow keys are "pijltoets omhoog/omlaag/links/rechts".
