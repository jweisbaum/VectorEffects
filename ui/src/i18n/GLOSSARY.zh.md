# 术语表（简体中文）

The terms of `GLOSSARY.md`, in the same order, in Simplified Chinese. Standard
mainland terminology: nautical charts (中国海事局/航海图书), CMA meteorology,
and the usual software-interface words.

Style: concise; 您 only where a sentence needs a pronoun. Buttons and menu
items are verb phrases or nouns ("保存", "另存为…"). Sentences use full-width
punctuation (，。：；？！ and “” for quotations and UI names); numbers, units
and `{placeholders}` stay ASCII, with no space between Chinese and adjacent
Latin text or numbers. Keep `…` where the English has it (it opens a dialog).
Keyboard keys keep the Latin names the English uses (Cmd, Shift, Alt, Esc,
Enter, Delete), except Backspace (退格键) and Space (空格键).

Never translated: see `GLOSSARY.md` (VectorEffects, GRIB, Zarr, UTC, EPSG,
units…).

Projection names (map picker, full names): 等距圆柱投影 (equirectangular),
兰勃特等积圆柱投影, 布劳恩球面圆柱投影, 中心圆柱投影, 地球仪（正射投影）,
正弦曲线投影, 方位等距投影, 兰勃特方位等积投影, 球面投影 (stereographic),
心射投影 (gnomonic). The stamp-space list uses short names without 投影:
墨卡托, 米勒, 兰勃特, 贝尔曼, 高尔–彼得斯, 霍博–戴尔, 高尔球面, 布劳恩,
中心圆柱, 帕特森, 紧凑米勒, 等距 30/45, 正射.

Other fixed choices: tile = 瓦片; render = 渲染; evaluator = 求值器; cell (ENC)
= 图幅; archive = 存档; routing (Zarr) = 航线规划; message (GRIB) = 消息;
step = 步 (“第 {step} 步”), time step = 时间步长; ease in/out = 缓入/缓出;
playhead = 播放头; handle = 控制柄; token = 令牌; patch = 贴片; opacity =
不透明度; Duplicate = 创建副本 (copy = 复制). Keys: Cmd, Shift, Alt, Esc,
Enter, Delete stay in Latin; Backspace = 退格键, Space = 空格键.
