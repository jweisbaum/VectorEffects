# Arabic glossary (العربية)

The Arabic terms for the application's own concepts, in the same order as the
table in `GLOSSARY.md`. Everything that file says about placeholders, `…` and
the never-translated names applies here too.

Register: Modern Standard Arabic. Sentences address the reader with the
imperative (انقر، اختر، افتح). Button and menu labels are verbal nouns
(حفظ، فتح، إغلاق، تصدير…), never imperatives, so a label reads the same in a
menu, a button and a history entry. No diacritics except where a word would be
ambiguous without them.

Digits are Western (0-9). Arabic sentences use the Arabic comma ، the Arabic
question mark ؟ and the Arabic semicolon ؛ quotations use « ». Latin tokens
(GRIB, km, {placeholders}, key names) are written where Arabic word order wants
them and left to the bidi algorithm; a string that would otherwise begin with a
Latin token or placeholder starts with an Arabic word, or failing that with
U+200F RIGHT-TO-LEFT MARK.

Keyboard keys keep the names macOS shows (Command, Shift, Option, Return,
Esc). Projection names are transliterated (ميركاتور، ميلر، لامبرت).
