# Glossario italiano

The Italian terms for the application's own concepts, in the same order as the
table in `GLOSSARY.md`. Conventions are there; the Italian ones in short:

Register: sentences use the impersonal and infinitive forms usual in Italian
software ("Fare clic per…", "Trascinare per…"); where a direct address cannot be
avoided, the formal "Lei" is not used — prefer the impersonal. Buttons and menu
items are imperatives in the tu-less software style ("Salva", "Apri",
"Esporta…"), as macOS and Office write them in Italian.

Punctuation: Italian uses « » for quotations, no space before `: ; ? !`. Keep
`…` where the English has it. Keep every `{placeholder}` exactly.

Keys: Invio, Esc, Maiusc, Canc, Opzione, Ctrl, Cmd, Spazio, Tab, frecce.
