# 用語集（日本語）

The Japanese terms for the application's own concepts, in the same order as
the table in `GLOSSARY.md`. Words follow Japanese nautical charts (海図),
JMA (気象庁) weather products and common Japanese software interfaces.

Style: polite です/ます in sentences, tooltips and hints; nouns or short verb
forms on buttons and menu items (保存, 開く…, 書き出し…). Japanese sentences use
full-width punctuation (、。「」（）：); numbers, units and `{placeholders}` stay
ASCII. UI names quoted in running text use 「」. Keep `…` where the English has
it. Keyboard keys are named as macOS shows them: Command, Shift, Option,
Control, Return, Esc, Delete. Projection names are katakana (メルカトル,
ミラー, ランベルト…). No space is inserted between Japanese and Latin text
except around placeholders where the English has one.
