# VectorEffects 0.1.13 Beta

This update adds image resize handles and fixes playback status, background
preparation after view changes, project loading, and image alignment.

**This beta expires on January 1, 2027.** Install a newer version before that
date to continue using VectorEffects.

## Downloads

Choose an installer from the release's Assets list:

| System | File |
| --- | --- |
| Intel Mac | `_x64.dmg` |
| Apple Silicon Mac (M-series) | `_aarch64.dmg` |
| Windows 64-bit | `-setup.exe` or `.msi` |
| Linux 64-bit | `.AppImage`, `.deb`, or `.rpm` |

`SHA256SUMS` contains checksums for the downloadable installers and app archives.
Mac builds without Developer ID credentials use ad-hoc signing without
notarization. Windows installers are unsigned.

## New

- **Resize reference images.** Select the image layer and use the Hand tool.
  Drag a corner to resize proportionally, or a side handle to stretch width or
  height. The opposite corner or side stays fixed. Existing alignment points
  move with the picture, and each drag is one Undo step.

## Fixed

- **Playback status.** The rolling preload count no longer says “preparing
  playback 2/3” while the animation is running. Preparation progress appears
  while paused; an actual wait for the next frame still reports “buffering.”
- **Background preparation follows the view.** Changing the camera or receiving
  a new projection mesh refreshes the tiles being prepared. The timeline clears
  readiness from the old view instead of retaining stale blue frames.
- **One project loading page.** Reading the project and preparing its first
  display share a single loading screen.
- **Alternating image alignment.** After a picture point is picked, its image
  hides while the matching map point is chosen. Hovering shows a magnified
  basemap without the image or field. Placing the map point restores the image;
  repeat until Enter. Backspace and Escape also restore it when appropriate.
- **Aligned pictures match their outlines.** One-, two-, and three-pair fits
  render at their fitted placement. Two-pair alignment preserves the image's
  orientation instead of reflecting it.
- **Image outlines follow curved projections.** Alignment by pointing is
  offered on cylindrical projections, where picture positions can be picked
  reliably.

## Known limitations

- Blue timeline frames describe backend rendering. A large project may still
  buffer while textures are transferred to the GPU.
- Pictures crossing the date line can appear folded in Robinson and other
  fixed world projections. The flat map and globe are unaffected.
