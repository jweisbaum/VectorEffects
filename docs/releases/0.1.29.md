# VectorEffects 0.1.29 Beta

This patch fixes Windows compatibility in the native AI assistant integration.
Shared-source checks now use the same filename order on every platform, and
backup files are opened with write access before flushing so replacing an
existing output can preserve its backup on Windows.

This release includes native AI assistant connections for Codex, Claude Code and
Claude Desktop. Open **Settings → AI assistants** to connect, test, repair or
disconnect an assistant. Restart the assistant after connecting; the settings
show Connected after its first successful tool call.

The native integration opens VectorEffects when needed and follows changes to
the local connection without requiring copied tokens or a reinstall. Choose a
permission policy when connecting: the default allows routine reads, edits,
downloads, saves and exports while reserving approval for irreversible actions.

Assistant exports run as background jobs that survive a disconnected client.
Repeated export requests with the same request ID reuse the existing job, and
switching projects refuses to discard unsaved work without an explicit discard.
Connection controls and permission descriptions are translated in the settings.

**This beta expires on January 1, 2027.** Install a newer version before that
date to continue using VectorEffects.

## Downloads

Choose an installer from the release's Assets list:

| System | File |
| --- | --- |
| Intel Mac | `_x64.dmg` |
| Apple Silicon Mac (M-series) | `_aarch64.dmg` |
| Windows 64-bit | `_x64-setup.exe` or `_x64_en-US.msi` |
| Windows on ARM | `_arm64-setup.exe` or `_arm64_en-US.msi` |
| Linux 64-bit | `.AppImage`, `.deb`, or `.rpm` |

`SHA256SUMS` contains checksums for the downloadable installers and app archives.
Mac builds without Developer ID credentials use ad-hoc signing without
notarization. Windows installers are unsigned.

## Known limitations

Claude Desktop completes extension installation and removal in its own settings.
The Test button checks that VectorEffects is reachable; an assistant tool call
verifies the complete connection.

ERA5 and GlobCurrent downloads fetch whole global hourly fields before
retaining the project region. Windows on ARM installers have not yet been
tested on a physical ARM computer. Translations have not yet been reviewed by
native speakers.
