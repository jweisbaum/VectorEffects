# VectorEffects 0.1.22 Beta

This release adds a native Windows on ARM build, imports every regional ICON
grid DWD publishes and the AROME files that would not open, and lets you
choose what an AI client may do in VectorEffects without asking.

## What's changed

- **Windows on ARM.** A native build for ARM-based Windows computers
  (Snapdragon and similar), alongside the 64-bit Windows build, which these
  computers could already run more slowly through emulation.
- **Regional ICON grids import.** ICON-D2, ICON-D2-EPS and ICON-EU-EPS files on
  their native icosahedral grids now import, beside ICON global and ICON-EPS.
  Outside a regional model's area the field is empty, rather than the
  model's edge wind spread across the rest of the earth, and a new project
  made from a regional file gets the 0.1° grid its kilometre-scale cells
  call for.
- **AROME files that would not open.** Some Météo-France AROME files,
  among them the 0.01° France grid, pack each field as one very wide
  compressed image, which the JPEG 2000 decoder refused. They now import.
  Météo-France's current files use another packing and already imported.
- **What an AI client may do without asking.** Settings → MCP has a new
  choice. By default an AI client may read, edit and move around a project
  without asking, since every edit can be undone, and asks before saving,
  exporting, downloading or discarding unsaved work. You can also choose to
  be asked before every action, or never. *Add to Claude Code* writes the
  matching permission rules into Claude Code's own settings, keeping any
  rules of your own; *Add to Codex* does the same for Codex. Press the Add
  button again after changing the choice or updating VectorEffects.

**This beta expires on January 1, 2027.** Install a newer version before that
date to continue using VectorEffects.

## Downloads

Choose an installer from the release's Assets list:

| System | File |
| --- | --- |
| Intel Mac | `_x64.dmg` |
| Apple Silicon Mac (M-series) | `_aarch64.dmg` |
| Windows 64-bit | `_x64-setup.exe` or `_x64_en-US.msi` |
| Windows on ARM | `_arm64-setup.exe` or `_arm64_en-US.msi` |
| Linux 64-bit | `.AppImage`, `.deb`, or `.rpm` |

`SHA256SUMS` contains checksums for the downloadable installers and app archives.
Mac builds without Developer ID credentials use ad-hoc signing without
notarization. Windows installers are unsigned.

## Known limitations

- The Windows on ARM build has passed its tests on GitHub's ARM runner but
  has not yet been installed on an ARM computer.
- How Claude Desktop treats the new permission choice is not yet known:
  it may still ask before each tool until you allow it there.
- An ensemble file imports its first member.
- Translations have not yet been reviewed by native speakers. Error messages
  that come from files and the engine stay as written.
- In Arabic the text reads right to left, but the workspace keeps its
  left-to-right arrangement.
- The app bundles no fonts: a Linux system without Japanese, Chinese or
  Arabic fonts installed may show those languages as empty boxes.
- Blue timeline frames describe backend rendering. A large project may still
  buffer while textures are transferred to the GPU.
- Pictures crossing the date line can appear folded in Robinson and other
  fixed world projections. The flat map and globe are unaffected.
- Near-real-time products trail the present by about a day, so the newest
  steps are usually empty. NOAA's CCMP server was unreachable while 0.1.21
  was prepared; it is offered, and named as skipped if it does not answer.
  A CMC download has not yet been tried with a real Earthdata token.
