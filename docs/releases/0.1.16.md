# VectorEffects 0.1.16 Beta

This release fixes moving a placed Displace.

## What's fixed

- **Displace source and destination move independently.** Dragging a placed
  Displace's body moves its source and leaves the orange destination outline
  where it is on the map. Drag inside the destination outline with the hand
  tool (or Shift-drag it with Displace) to move only the destination. Each
  drag is a single undo, and animated displacements are keyed by the same
  rule as the position.

**This beta expires on January 1, 2027.** Install a newer version before that
date to continue using VectorEffects.

## Downloads

Choose an installer from the release's Assets list:

| System | File |
| --- | --- |
| Intel Mac | `_x64.dmg` |
| Apple Silicon Mac (M-series) | `_aarch64.dmg` |
| Windows 64-bit | `-setup.exe` or `.msi` |
| Linux 64-bit | `.AppImage`, `.deb`, or `.rpm` |

`SHA256SUMS` contains checksums for the downloadable installers and app archives.
Mac builds without Developer ID credentials use ad-hoc signing without
notarization. Windows installers are unsigned.

## Known limitations

- Blue timeline frames describe backend rendering. A large project may still
  buffer while textures are transferred to the GPU.
- Pictures crossing the date line can appear folded in Robinson and other
  fixed world projections. The flat map and globe are unaffected.
