# VectorEffects 0.1.24 Beta

This release adds Whirlwind Hindsight history sources, improves historical
download progress and date validation, and fixes the theme flash at startup.

## What's changed

- **Choose a history source.** Settings offers Open Data and three Whirlwind
  Hindsight mirrors, labeled S3, R2 and Tigris. Open Data remains the default.
  Downloaded wind and current layers record their source.
- **Faster Whirlwind downloads.** Wind and current share archive reads, nearby
  byte ranges are combined, independent requests run concurrently, and reusable
  compressed data is cached in memory and on disk. Downloads request the inner
  chunks covering the project and selected times. These optimizations apply to
  Whirlwind history imports.
- **More responsive progress.** History downloads show preparation, reading
  and import stages, with progress and transferred bytes updating during reads.
- **Dates match the selected source.** The history dialog reads the archive's
  current coverage, warns with its specific start and end dates, and prevents
  imports outside that range. Whirlwind coverage comes from completed archive
  records rather than fixed dates or an assumed delay behind the present.
- **Missing archive chunks no longer stop the import unexpectedly.** Empty
  chunks produce missing data instead of overflowing the shard index reader.
- **The saved theme appears from the start.** The window opens after the
  saved theme and language have been applied.

**This beta expires on January 1, 2027.** Install a newer version before that
date to continue using VectorEffects.

Choose an installer from the release's Assets list:

| System | File |
| --- | --- |
| Intel Mac | `_x64.dmg` |
| Apple Silicon Mac (M-series) | `_aarch64.dmg` |
| Windows 64-bit | `_x64-setup.exe` or `_x64_en-US.msi` |
| Windows on ARM | `_arm64-setup.exe` or `_arm64_en-US.msi` |
| Linux 64-bit | `.AppImage`, `.deb`, or `.rpm` |

`SHA256SUMS` contains checksums for the downloadable installers and app archives.
Mac builds without Developer ID credentials use ad-hoc signing without
notarization. Windows installers are unsigned.

## Known limitations

- During verification, the S3 mirror allowed object reads but refused the
  listing needed to discover completed archive dates. Imports from that mirror
  are blocked while its coverage cannot be verified. R2 and Tigris provided
  the required inventory.
- Archive preparation and download speed depend on the selected provider.
  Missing steps inside the advertised date range remain missing data.
- The current Whirlwind archive compresses wind, current and wave variables
  together in each inner chunk, so reads also transfer the wave values. If a
  server ignores a byte-range request, the reader can fall back to receiving
  the whole shard. All three mirrors honored the tested range requests.
- ERA5 and GlobCurrent downloads still fetch whole global hourly fields before
  retaining the project region.
- Windows on ARM installers have not yet been tested on a physical ARM computer.
- Translations have not yet been reviewed by native speakers. Engine and file
  errors retain their original language, and Arabic uses a left-to-right
  workspace layout. The app relies on system fonts for all languages.
