# VectorEffects 0.1.6 Beta

This update adds Zarr V3 export beside GRIB2 and corrects macro placement and
several editing interactions.

**This beta expires on January 1, 2027.** Install a newer version before that
date to continue using VectorEffects.

## Downloads

Choose an installer from the release's Assets list:

| System | File |
| --- | --- |
| Intel Mac | `_x64.dmg` |
| Apple Silicon Mac (M-series) | `_aarch64.dmg` |
| Windows 64-bit | `-setup.exe` or `.msi` |
| Linux 64-bit | `.AppImage`, `.deb`, or `.rpm` |

`SHA256SUMS` contains checksums for the downloadable installers and app archives.
Mac builds without Developer ID credentials use ad-hoc signing without
notarization. Windows installers are unsigned; the operating system may require
approval before launch.

## New

- **Export Zarr…** writes the evaluated vectors as a filesystem Zarr V3 directory. One Float16 `/data` array carries `u10m_wind`, `v10m_wind`, `u_total_surface_current`, and `v_total_surface_current` in its parameter dimension, chunked 72 hours by 10° at the project resolution and compressed with Zstd. Uncovered cells are NaN, so the land mask survives; painted calm remains a real zero. The array's attributes record the reference time, the step, and the grid origin. The dialog asks for the same forecast start time as GRIB export, and an existing directory is refused rather than overwritten.
- Zarr and GRIB exports of one project put every cell in the same place, evaluated through the same CPU export path.

## Fixes and improvements

- Macro placement uses only the selected painted layer's recorded field plane, with a crossed hover and no command for an incompatible destination.
- In-page tool menus keep the next map press available to drawing.
- The toolbar centres and sizes to its contents, inspector sliders stack, and ruler drags no longer select page text.
- Captured macros and patches no longer show shape-animation controls.
- Brush and Shape fill Direction mode, Circle Fill, Clone Offset, Path Direction mode, Mask Invert, and Warp mode and Push to are editable constants.
- The last layer can be deleted, leaving the basemap, and restored with Undo.
- Help documents Zarr export alongside GRIB export.

The preceding source commit passed CI on Intel Mac, Apple Silicon Mac, Windows,
and Linux. Each installer build repeats the native/UI checks, generated-binding
check, and offline check.
