# VectorEffects 0.1.23 Beta

This release adds regional projects: a project can cover one part of the
earth instead of the whole of it, and everything it imports, downloads and
exports is kept to that part, so its files are a fraction of the size.

## What's changed

- **Global or regional.** When you create a project you now choose its
  extent. A regional project covers a rectangle of latitude and longitude:
  drag it on the small map in the new-project form, or type its north,
  south, west and east edges. A rectangle may cross the date line, and the
  map turns as you drag so you can draw across it. *Arctic* and *Antarctic*
  fill a polar cap from 60° to the pole, and *Full circle* makes a band all
  the way round. Like the resolution and the time step, the region cannot
  be changed after the project is created.
- **Use current view.** *Project → New…* can take the region from what the
  map is showing.
- **Projects from files.** *Open from GRIB* and *Open from Zarr* make a
  regional project when the file covers only part of the earth, fitted to
  where the file has data. A global file still makes a global project.
- **The map stays on the region.** A regional project opens fitted to its
  region, and you cannot zoom out past it or pan away from it, in every
  projection. Outside the region the map is dimmed, and a stroke has to
  start inside it. The status bar shows the region.
- **Smaller downloads and files.** Imports are trimmed to the region, and
  history and near-real-time downloads keep only the region. For a 40° by
  20° area of the Pacific, a day of ERA5 wind is 1.3 MB on disk instead of
  about 100 MB. Copernicus Marine and NOAA's ERDDAP servers are asked for the
  region alone.
- **Exports on the region.** A GRIB export is written on the region's own
  grid. A Zarr export keeps the usual routing layout, so routing tools read
  it as before, and writes only the chunks that cover the region.
- **AI clients.** The MCP `project_new` tool takes a region, including one
  that crosses the date line.

**This beta expires on January 1, 2027.** Install a newer version before that
date to continue using VectorEffects.

## Downloads

Choose an installer from the release's Assets list:

| System | File |
| --- | --- |
| Intel Mac | `_x64.dmg` |
| Apple Silicon Mac (M-series) | `_aarch64.dmg` |
| Windows 64-bit | `_x64-setup.exe` or `_x64_en-US.msi` |
| Windows on ARM | `_arm64-setup.exe` or `_arm64_en-US.msi` |
| Linux 64-bit | `.AppImage`, `.deb`, or `.rpm` |

`SHA256SUMS` contains checksums for the downloadable installers and app archives.
Mac builds without Developer ID credentials use ad-hoc signing without
notarization. Windows installers are unsigned.

## Known limitations

- ERA5 and GlobCurrent store each hour as one piece covering the whole
  earth, so a regional download of them still fetches the globe and keeps
  only the region.
- On the globe and the azimuthal maps, a band all the way round the earth,
  or a region wider than a hemisphere, is not dimmed outside. It still
  cannot be panned away from, and strokes outside it are still refused.
- In Robinson and other fixed world projections, a region that the map's
  own edge cuts in two, such as one centred on the date line, can be zoomed
  out to the whole world.
- How an AI client picks a region from a plain request has not yet been
  tried.
- The Windows on ARM build has passed its tests on GitHub's ARM runner but
  has not yet been installed on an ARM computer.
- How Claude Desktop treats the MCP permission choice is not yet known:
  it may still ask before each tool until you allow it there.
- An ensemble file imports its first member.
- Translations, including this release's new text, have not yet been
  reviewed by native speakers. Error messages that come from files and the
  engine stay as written.
- In Arabic the text reads right to left, but the workspace keeps its
  left-to-right arrangement.
- The app bundles no fonts: a Linux system without Japanese, Chinese or
  Arabic fonts installed may show those languages as empty boxes.
- Blue timeline frames describe backend rendering. A large project may still
  buffer while textures are transferred to the GPU.
- Pictures crossing the date line can appear folded in Robinson and other
  fixed world projections. The flat map and globe are unaffected.
- Near-real-time products trail the present by about a day, so the newest
  steps are usually empty. NOAA's CCMP server was unreachable while 0.1.21
  was prepared; it is offered, and named as skipped if it does not answer.
  A CMC download has not yet been tried with a real Earthdata token.
