# VectorEffects 0.1.5 Beta

This update fixes clone transparency and editing interactions and adds a detailed
illustrated Help reference.

**This beta expires on January 1, 2027.** Install a newer version before that
date to continue using VectorEffects.

## Downloads

Choose an installer from the release's Assets list:

| System | File |
| --- | --- |
| Intel Mac | `_x64.dmg` |
| Apple Silicon Mac (M-series) | `_aarch64.dmg` |
| Windows 64-bit | `-setup.exe` or `.msi` |
| Linux 64-bit | `.AppImage`, `.deb`, or `.rpm` |

`SHA256SUMS` contains checksums for the downloadable installers and app archives.
Mac builds without Developer ID credentials use ad-hoc signing without
notarization. Windows installers are unsigned; the operating system may require
approval before launch.

## Fixes and improvements

- Clone stamps copy only defined vector data, preserving source holes in both the live preview and the committed result. Defined calm still copies correctly.
- Feather defaults to zero for new tools and the eraser. Circle's angle from tangent is a −90° to +90° slider, and Path's fixed direction mode is called Constant.
- Changing a tool setting no longer consumes the next map click.
- Timeline lifetime handles are easier to grab and keep their released position while the document refreshes.
- Deleted objects are removed from selection after undo or deletion. Obsolete inspector and shape reads no longer produce stale missing-object errors.
- Divergence and convergence controls explicitly identify outward and inward flow. Help explains the wind-barb direction convention; the physical vector math is unchanged.
- GRIB export removes centre and precision choices and includes “Created with VectorEffects” in every message. Undefined cells remain distinct from defined zero-speed data.
- Help now contains 33 searchable pages with parameter and option descriptions, related workflows, and 36 enlargeable screenshots. Open it from the Help menu or F1.

The preceding source commit passed CI on Intel Mac, Apple Silicon Mac, Windows,
and Linux. Each installer build repeats the native/UI checks, generated-binding
check, and offline check. Local validation also covered physical Metal rendering,
WebKit clone/glyph/help rendering, and independent ecCodes GRIB decoding.

Projects and Help work offline. Historical wind/current data is downloaded only
when requested. This beta has no automatic updater.
