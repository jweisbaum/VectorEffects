# VectorEffects 0.1.11 Beta

This update puts electronic charts, OpenStreetMap and your own GIS data under
the field.

It supersedes 0.1.10, which was tagged but never published: charts drew over
the field there rather than under it.

**This beta expires on January 1, 2027.** Install a newer version before that
date to continue using VectorEffects.

## Downloads

Choose an installer from the release's Assets list:

| System | File |
| --- | --- |
| Intel Mac | `_x64.dmg` |
| Apple Silicon Mac (M-series) | `_aarch64.dmg` |
| Windows 64-bit | `-setup.exe` or `.msi` |
| Linux 64-bit | `.AppImage`, `.deb`, or `.rpm` |

`SHA256SUMS` contains checksums for the downloadable installers and app archives.
Mac builds without Developer ID credentials use ad-hoc signing without
notarization. Windows installers are unsigned; the operating system may require
approval before launch.

## New

- **Electronic charts (S-57).** Point **Settings → Charts** at an ENC exchange set — the folder you unzipped, the one holding the cell folders — and turn charts on with **Charts** in the view controls. They are drawn under everything, follow every projection including the globe, and are not layers: nothing appears in the layer panel, because a chart is how you are looking at the map rather than part of your project. Cells are chosen by their usage band as you zoom, so a harbour plan paints over the coastal chart it sits inside. What is drawn is a legible chart rather than the full S-52 symbol set: water shaded by depth, depth contours, the coastline, and a mark for every sounding, buoy, beacon, light, wreck, rock and obstruction, with restricted and caution areas outlined. Base editions (`.000`) only — update files are not applied.
- **OpenStreetMap.** A checkbox in the view controls that replaces the built-in basemap with OpenStreetMap's own. It works in every projection, the globe included. **Tiles are fetched only while the box is ticked**, and kept on disk so panning does not ask twice; everything else in VectorEffects stays offline, exactly as before. Maps shown this way carry *© OpenStreetMap contributors*.
- **GIS import.** **+ GIS** in the layer panel reads a shapefile (`.shp` with its `.dbf` and `.prj`), GeoJSON, KML or KMZ and adds it as a layer you can colour, set a line width for, and fill. It is display only: it makes no wind, and reaches no export. A georeferenced raster picked in the same dialog becomes an image layer instead, as before. A file in a projected coordinate system is refused by name rather than drawn in the wrong place.

## Fixes and improvements

- Charts and GIS layers are drawn **under** everything you paint. In 0.1.10's build they were drawn after the field, and a chart's deep water is opaque, so it covered whatever was underneath wherever a chart cell reached.
- The layer panel is wider, so the history button no longer sits behind a horizontal scroll — and the panel's collapse handle stays on its edge, where it belongs.

Each installer build repeats the native/UI checks, generated-binding check, and
offline check on its own platform before bundling.

Projects and Help work offline. Historical wind/current data and OpenStreetMap
tiles are downloaded only when you ask for them, and the MCP service accepts
connections only from this computer and only while it is switched on. This beta
has no automatic updater.
