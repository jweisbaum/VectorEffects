# VectorEffects 0.1.1 Beta

Paint, animate, import, and export global wind and ocean-current fields.

**This beta expires on January 1, 2027.** Install a newer version before that
date to continue using VectorEffects.

## Downloads

Choose an installer from the release's Assets list:

| System | File |
| --- | --- |
| Intel Mac | `_x64.dmg` |
| Apple Silicon Mac (M-series) | `_aarch64.dmg` |
| Windows 64-bit | `-setup.exe` or `.msi` |
| Linux 64-bit | `.AppImage`, `.deb`, or `.rpm` |

`SHA256SUMS` contains checksums for the downloadable installers and app archives.
These initial beta builds use ad-hoc Mac signing without notarization and unsigned
Windows installers; the operating system may require approval before launch.

## Release build fixes

- Virtualized Intel Macs use CPU rendering when Apple’s virtual GPU cannot meet the field-fidelity tolerance. Physical GPUs retain accelerated rendering.
- GRIB validation handles bitmap APIs in both distribution-packaged and current ecCodes versions.
- The build pipeline supports unsigned/ad-hoc signed beta installers and fits within hosted runner disk limits.

## Included improvements

- Faster playback preparation for GRIB and Zarr layers and faster historical data imports.
- Drag layers and objects to change their drawing order.
- Animate object outlines with perimeter control points; erasing removes geometry from animated shapes.
- Macro frame strategies: Repeat Frames, Empty Frames, or interpolation of vectors and motion.
- Great-circle and rhumb-line target directions, angle offsets, circle direction controls, and global distance/speed units.
- Arrow and wind-barb appearance settings, with more even coverage in narrow fields.
- Consistent pixel brushes across projections and previews containing only the dragged object.
- Constant-motion position keyframes and speed thresholds for every layer type.
- Retry failed historical downloads and hide missing recent projects.
- GRIB export preserves undefined regions separately from defined calm water or wind.
- Built-in Help with screenshots, available from the Help menu or F1.

Projects and help content work offline. Historical wind/current data is downloaded
only when requested. This beta has no automatic updater.
