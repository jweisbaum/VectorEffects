# VectorEffects 0.1.9 Beta

This update adds the globe and 250 other map projections, opens routing Zarr
stores as layers, shows a loading page with a real progress bar, and makes
opening projects and moving the map many times faster.

**This beta expires on January 1, 2027.** Install a newer version before that
date to continue using VectorEffects.

## Downloads

Choose an installer from the release's Assets list:

| System | File |
| --- | --- |
| Intel Mac | `_x64.dmg` |
| Apple Silicon Mac (M-series) | `_aarch64.dmg` |
| Windows 64-bit | `-setup.exe` or `.msi` |
| Linux 64-bit | `.AppImage`, `.deb`, or `.rpm` |

`SHA256SUMS` contains checksums for the downloadable installers and app archives.
Mac builds without Developer ID credentials use ad-hoc signing without
notarization. Windows installers are unsigned; the operating system may require
approval before launch.

## New

- **Map projections.** The projection button in the title bar opens a searchable list: an orthographic **globe** and movable azimuthal equidistant, equal-area, stereographic and gnomonic views — drag one to change its centre — Robinson, Mollweide, Winkel Tripel, Equal Earth and Sinusoidal world maps, more cylindrical maps, and 246 polar and regional grids, from the NSIDC sea-ice grids to British National Grid, Swiss LV95, NZTM and every UTM zone. A PROJ or WKT definition can be pasted in as a custom projection. All of it works offline. A projection is a way of looking: what you paint and what you export do not change with it.
- **Routing Zarr stores as layers.** *Import Zarr* in the layer panel and *Open from Zarr* on the start screen read a routing store (the layout **Export Zarr** writes) as ordinary wind and current layers, with the same timeline, speed filter, eraser and export as a GRIB layer.
- **A loading page.** Opening a project, a recent project, recovered work, or a project from a GRIB or Zarr shows what is being read and how much of it — "routing_test · 312 of 1,488" — on a bar that is a real fraction, and stays until the map has drawn. A layer whose file has gone missing is named in the status bar when the project opens.
- **`vectoreffects_guide`** gives an MCP client the full guide to the service's tools as a tool, for clients that do not pass a server's instructions to the model. *Add to Claude Code* also installs it as a skill, and *Add to Claude Desktop* saves one as a zip to upload by hand; the dialog says where.

## Faster

- **Opening.** A project with an imported GRIB opens in a third of a second where it took nine: a file holding wind and currents was decoded once per layer, its messages one after another, and each frame was checksummed four bytes at a time. A month of hourly wind from a routing Zarr store opens in eleven seconds where it took two minutes — the store was being read in pieces that cut across its compressed chunks, so each chunk was decompressed nine times. Tiles and edits no longer wait behind a Zarr import.
- **Turning the globe.** A frame of turning took most of a second; it takes a few milliseconds. The globe and the azimuthal views are now projected by the graphics card.
- **Panning and zooming the other projections.** Robinson, Mollweide and the regional grids rebuilt their map mesh on every pointer move — half a second a frame, a second for Mollweide. It is built once, off the main thread, and moved.
- **Wind barbs and arrows** under these projections are placed in a fraction of the time, for the same marks.

## Fixes and improvements

- Dividers and measurements draw correctly on the globe, and a brush sized in pixels has the right footprint under every projection.
- The layer panel's import buttons take less room.
- The MCP service's instructions now fit what a client actually keeps, lead with when to use the service, and its tools say whose they are.

Each installer build repeats the native/UI checks, generated-binding check, and
offline check on its own platform before bundling.
