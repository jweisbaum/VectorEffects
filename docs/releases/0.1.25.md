# VectorEffects 0.1.25 Beta

The historical Import button now looks disabled while the app checks the
selected source's available dates. It is dimmed, uses the normal cursor,
and has no hover highlight until the check succeeds and the requested dates
are valid. The existing protection against starting an unverified or invalid
download remains in place.

The same disabled appearance applies to other dialog action buttons.

**This beta expires on January 1, 2027.** Install a newer version before that
date to continue using VectorEffects.

## Downloads

Choose an installer from the release's Assets list:

| System | File |
| --- | --- |
| Intel Mac | `_x64.dmg` |
| Apple Silicon Mac (M-series) | `_aarch64.dmg` |
| Windows 64-bit | `_x64-setup.exe` or `_x64_en-US.msi` |
| Windows on ARM | `_arm64-setup.exe` or `_arm64_en-US.msi` |
| Linux 64-bit | `.AppImage`, `.deb`, or `.rpm` |

`SHA256SUMS` contains checksums for the downloadable installers and app archives.
Mac builds without Developer ID credentials use ad-hoc signing without
notarization. Windows installers are unsigned.

## Known limitations

The [0.1.24 limitations](https://github.com/jweisbaum/VectorEffects/releases/tag/v0.1.24)
still apply. In particular, the Whirlwind S3 source cannot be imported while
its archive dates cannot be verified; R2 and Tigris provided the required
inventory during verification.
