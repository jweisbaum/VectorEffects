# VectorEffects 0.1.19 Beta

This release refines the new interface languages and fixes the zoom readout.

## What's changed

- **Language on the start page.** The language picker is back on the start
  page, so a language can be chosen before opening a project. It is also in
  Settings → Appearance. The start page no longer shows the Help menu.
- **Default names in your language.** New layers, new objects, duplicates and
  unnamed projects are named in the selected language ("Ebene 2", "Kreis 1",
  "Kreis 1 Kopie"). Names already given stay as they are when the language
  changes.

## What's fixed

- **The zoom readout follows the map.** The percentage in the cursor readout
  now updates as you zoom with the wheel, a trackpad, keys or buttons, not only
  when the pointer moves.

**This beta expires on January 1, 2027.** Install a newer version before that
date to continue using VectorEffects.

## Downloads

Choose an installer from the release's Assets list:

| System | File |
| --- | --- |
| Intel Mac | `_x64.dmg` |
| Apple Silicon Mac (M-series) | `_aarch64.dmg` |
| Windows 64-bit | `-setup.exe` or `.msi` |
| Linux 64-bit | `.AppImage`, `.deb`, or `.rpm` |

`SHA256SUMS` contains checksums for the downloadable installers and app archives.
Mac builds without Developer ID credentials use ad-hoc signing without
notarization. Windows installers are unsigned.

## Known limitations

- Translations have not yet been reviewed by native speakers. Error messages
  that come from files and the engine stay as written.
- In Arabic the text reads right to left, but the workspace keeps its
  left-to-right arrangement.
- The app bundles no fonts: a Linux system without Japanese, Chinese or
  Arabic fonts installed may show those languages as empty boxes.
- Blue timeline frames describe backend rendering. A large project may still
  buffer while textures are transferred to the GPU.
- Pictures crossing the date line can appear folded in Robinson and other
  fixed world projections. The flat map and globe are unaffected.
