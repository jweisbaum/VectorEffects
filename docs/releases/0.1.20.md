# VectorEffects 0.1.20 Beta

This release adds near-real-time observed data — the last days of wind,
currents and sea-surface temperature, up to now — and a measurement of how
fast a feature moves.

## What's new

- **Near-real-time data.** A new button beside the history calendar fetches
  the last N days of observed data, up to the current hour, and adds one
  layer per product. It can set or move the timeline's start to the
  beginning of the period, and lengthen the timeline to reach the present.
  Ten products:
  - Currents: Copernicus MULTIOBS (hourly) and DUACS (daily).
  - Wind: Copernicus L4 (hourly), ASCAT Metop-B/C (daily, the day's passes
    merged), CCMP NRT and NOAA Blended Seawinds (six-hourly).
  - Sea-surface temperature: NOAA OISST, NOAA Geo-Polar Blended, OSTIA and
    CMC (daily).

  A daily product is shown on every step of its day. A product that cannot
  be fetched is named in the status bar while the others still arrive.
- **Sea-surface temperature layers.** Drawn in colour under the field, with
  their own legend and the temperature under the pointer in the readout.
  They are display only: never painted on or exported. Settings chooses
  °C or °F.
- **CMC needs a NASA Earthdata token**, set in Settings → NASA Earthdata. It
  is kept in a file of its own, sent only to NASA's PO.DAAC archive, and
  never shown again or given to an AI client.
- **Feature speed.** A fourth measurement: click a feature, step forward in
  time, click it again, and read its average speed and direction between
  the two.
- **Timeline alignment.** On a timeline with a start time, an imported
  layer whose fields do not fall on the steps' times is highlighted, with
  the offset in its tooltip. A button beside its name lines it up; one Undo
  puts it back. Nothing is blocked and export is unaffected.
- **One Import button.** GRIB2 files, routing Zarr stores, images and GIS
  data are imported from one button, whose dialog lists only the formats
  the application reads. A Zarr store is chosen by the `zarr.json` file at
  its top.
- **An AI client can fetch near-real-time data** through the MCP service
  (`nrt_products`, `import_nrt`).

**This beta expires on January 1, 2027.** Install a newer version before that
date to continue using VectorEffects.

## Downloads

Choose an installer from the release's Assets list:

| System | File |
| --- | --- |
| Intel Mac | `_x64.dmg` |
| Apple Silicon Mac (M-series) | `_aarch64.dmg` |
| Windows 64-bit | `-setup.exe` or `.msi` |
| Linux 64-bit | `.AppImage`, `.deb`, or `.rpm` |

`SHA256SUMS` contains checksums for the downloadable installers and app archives.
Mac builds without Developer ID credentials use ad-hoc signing without
notarization. Windows installers are unsigned.

## Known limitations

- Translations have not yet been reviewed by native speakers. Error messages
  that come from files and the engine stay as written.
- In Arabic the text reads right to left, but the workspace keeps its
  left-to-right arrangement.
- The app bundles no fonts: a Linux system without Japanese, Chinese or
  Arabic fonts installed may show those languages as empty boxes.
- Blue timeline frames describe backend rendering. A large project may still
  buffer while textures are transferred to the GPU.
- Pictures crossing the date line can appear folded in Robinson and other
  fixed world projections. The flat map and globe are unaffected.
- Near-real-time products trail the present by about a day, so the newest
  steps are usually empty. NOAA's CCMP server was unreachable while this
  release was prepared; it is offered, and named as skipped if it does not
  answer. A CMC download has not yet been tried with a real Earthdata
  token.
