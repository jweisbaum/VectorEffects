# VectorEffects 0.1.15 Beta

This release improves globe editing, introduces the two-step Displace tool,
and adds application-wide themes and custom colors.

## What's new

- **Themes and custom colors.** Choose Original (Midnight), Sage & Teal, Ocean,
  Plum, Ember, or Paper in Settings. Palette swatches preview each choice.
  Customize interface, map, and chart colors with color pickers, hex inputs,
  and a preview. Preferences persist across projects and restarts.
- **Displace.** Brush a region, release, then drag it to its destination. The
  interior is preserved while surrounding data and the vacated area are
  interpolated. Feather and interpolation distance control the transition.
  Source position, relative displacement, and interpolation distance animate
  independently. The source and orange destination outlines show a connecting
  line, and the timeline uses a single Displacement position row.
- **Globe pixel tools.** Committed brush, circle, and shape-fill footprints
  match their pixel-mode previews, including near the edge of the globe.
- **Smoother copies and macros.** Region captures retain more source detail,
  with smoother curved boundaries. Selection outlines follow the globe's
  surface. Existing captures gain smoother edges; recapture to retain more
  detail from their sources.
- **Workspace improvements.** Launch maximized instead of full screen. Tool
  buttons stay centered and stationary, with options underneath. Project
  commands share one dropdown; Legend is the final view option. Start-page
  sections have more spacing, and unwanted blue focus bars are removed.

Existing projects are migrated when opened, including prior displacement
animation tracks. Legacy Smear objects keep their existing behavior.

**This beta expires on January 1, 2027.** Install a newer version before that
date to continue using VectorEffects.

## Downloads

Choose an installer from the release's Assets list:

| System | File |
| --- | --- |
| Intel Mac | `_x64.dmg` |
| Apple Silicon Mac (M-series) | `_aarch64.dmg` |
| Windows 64-bit | `-setup.exe` or `.msi` |
| Linux 64-bit | `.AppImage`, `.deb`, or `.rpm` |

`SHA256SUMS` contains checksums for the downloadable installers and app archives.
Mac builds without Developer ID credentials use ad-hoc signing without
notarization. Windows installers are unsigned.

## Known limitations

- Blue timeline frames describe backend rendering. A large project may still
  buffer while textures are transferred to the GPU.
- Pictures crossing the date line can appear folded in Robinson and other
  fixed world projections. The flat map and globe are unaffected.
