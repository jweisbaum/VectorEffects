# VectorEffects 0.1.27 Beta

This release carries the 0.1.26 changes, which never published: its release
run failed on the checks that the removal of the Whirlwind Hindsight history
sources left behind. The translation catalogues held eleven progress and
settings strings that nothing used any more, and a generated TypeScript binding
had been edited by hand. Both are corrected here.

As in 0.1.26, the Whirlwind Hindsight mirrors are no longer historical data
sources. Historical imports use the public ERA5 archive for 10 m wind and
GlobCurrent for surface currents. The source selector and Hindsight download
code have been removed; previously imported layers remain ordinary project
layers.

**This beta expires on January 1, 2027.** Install a newer version before that
date to continue using VectorEffects.

## Downloads

Choose an installer from the release's Assets list:

| System | File |
| --- | --- |
| Intel Mac | `_x64.dmg` |
| Apple Silicon Mac (M-series) | `_aarch64.dmg` |
| Windows 64-bit | `_x64-setup.exe` or `_x64_en-US.msi` |
| Windows on ARM | `_arm64-setup.exe` or `_arm64_en-US.msi` |
| Linux 64-bit | `.AppImage`, `.deb`, or `.rpm` |

`SHA256SUMS` contains checksums for the downloadable installers and app archives.
Mac builds without Developer ID credentials use ad-hoc signing without
notarization. Windows installers are unsigned.

## Known limitations

ERA5 and GlobCurrent downloads fetch whole global hourly fields before
retaining the project region. Windows on ARM installers have not yet been
tested on a physical ARM computer. Translations have not yet been reviewed by
native speakers.
