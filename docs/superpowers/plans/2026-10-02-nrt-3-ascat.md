# Near-real-time data, milestone 3: ASCAT — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A fourth product in the near-real-time dialog: ASCAT scatterometer wind from Metop-B and Metop-C, one layer per day, the four passes of each day merged, with no value where no satellite passed.

**Architecture:** Four Copernicus stores (`…l3-{metopb,metopc}-ascat-{asc,des}-0.25deg_P1D-i`) are each read by the existing `ArcoStore`, extended to read a per-cell time array beside `u` and `v`. A new `AscatStore` implements `FieldSource` over the four: its time axis is the union of their days, and `read_step` merges the passes cell by cell, the most recent measurement winning, before the regrid. Everything after that — the product catalogue, the import, the dialog — gains one entry.

**Spec:** `docs/superpowers/specs/2026-10-02-near-real-time-data-design.md` §2 (the ASCAT assumption), §4, §8 milestone 3.

## Global Constraints

As milestone 2's: invariant 5 (same host, nothing new), the 0.25° grid, the period held for 24 h, nine languages, the Help search, one commit, the disk settings.

## Rulings taken while planning

- **Metop-A is left out.** The catalogue lists it, the user named B and C, and Metop-A was retired from the operational constellation. Cost if wrong: one more dataset in a list.
- **The merge is per cell by `measurement_time`**, the most recent winning; a cell no pass measured stays missing. Cost if wrong: where two passes overlap within a day, the older is dropped.
- **A day's frame is stamped at the store's own time** (observed: midnight), floored to the day in `AscatStore` so the midnights the import asks for are found whatever the publisher stamps.

## Review Focus

1. A day one satellite has and the other lacks: the day is present, from the one that has it.
2. Two passes measuring the same cell: the later `measurement_time` wins; a pass whose time is the fill value does not win.
3. A cell no pass measured: missing in the file (bitmap), not zero.
4. A day no pass has at all inside the period: skipped like a missing day, the layer counting from the period's start as the padding rule says.
5. The regrid of a swath with gaps: a node whose four cells are all missing is missing; one with some is the mean of those.

### Task 1: `ArcoStore` reads a time array beside the components

**Files:** `crates/ve-zarr/src/arco.rs`.

- `ArcoSpec` gains `pub time_path: Option<&'static str>` (every existing spec: `None`).
- `pub fn read_native_timed(&self, step: &Step) -> Result<(Vec<f32>, Vec<f32>, Option<Vec<f64>>)>` — `u`, `v` on the store's grid, and the per-cell time in seconds since the Unix epoch (`f64`, NaN where fill), read from a float64 array with `units` "seconds since …" parsed by `parse_time_units`.
- Test: `unpack_time(raw, fill, base_s)` on `-2147483647.0` with that fill gives NaN; `1_159_660_800.0` since 1990 gives the hand-worked Unix seconds of 2026-10-01T00Z (`20_727 * 86_400 = 1_790_812_800`).

### Task 2: `AscatStore`

**Files:** Create `crates/ve-zarr/src/ascat.rs`; modify `lib.rs`.

- `pub fn merge_passes(passes: &[(Vec<f32>, Vec<f32>, Vec<f64>)]) -> (Vec<f32>, Vec<f32>)` — per cell, the pass with the greatest finite time; NaN where none.
- `pub struct AscatStore { members: Vec<ArcoStore>, days: Vec<i64> /* hours */ }`, `open(urls: &[String]) -> Result<Self>` requiring every member on `CellGrid::GLOBCURRENT`'s shape (720 × 1440), `impl FieldSource` with `variables` = `[Wind10m]`, days = the union of members' days floored to midnight, `read_step` reading every member that has the day (`try_join` in pairs is enough), merging, regridding.
- Tests: `merge_passes` on three cells — one measured by A only, one by both with B later, one by neither; a pass with NaN time loses; a day present in one member only is in `days` once.
